# Security Policy

Engineering OS is an experimental public project. Security reports should be handled privately whenever possible.

## Reporting a vulnerability

**Do not open a public GitHub issue with exploit details, credentials, or sensitive proof-of-concept material.**

Preferred channels:

1. Use GitHub's private vulnerability reporting / security advisory flow for this repository when available.
2. Email **veluneproductions@gmail.com** when private reporting is not available.

Please include the affected version or commit, impact, reproduction steps, and any mitigations you know. Keep secrets and real user data out of the report.

## What to expect

- We will acknowledge receipt when practical.
- We will assess severity and reproducibility.
- Fixes may be shipped as a normal release, a security release, or a documented mitigation.
- Please give maintainers reasonable time to investigate before public disclosure.

## Scope

This policy covers the Engineering OS repository and the code distributed from it. Third-party products, Claude Code itself, and infrastructure outside this repository should be reported to their respective maintainers.
