# Support

## Questions and usage help

For questions about using Engineering OS, open a GitHub Discussion when the topic is exploratory or does not require a tracked change.

For a reproducible defect, use the **Bug report** issue form. Include the Claude Code version, plugin version or commit, operating system, reproduction steps, and concise evidence.

For a concrete improvement, use the **Feature request** form. For bounded maintenance work, use the **Engineering task** form.

## Before opening a report

Please search existing Issues and Discussions first. Remove secrets, private data, credentials, and sensitive exploit details from anything posted publicly.

## Security

Do not use public Issues or Discussions for vulnerability details. Follow [SECURITY.md](SECURITY.md).
